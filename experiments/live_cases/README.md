# Preserved live cases, 2026-09-22

These are the exact generated programs from two completed Research Harness
workflows. **Both research packages were rejected by their acceptance gates.**
They are retained as executable failure evidence, not recommended algorithms.
Comments inside the generated programs may themselves contain incorrect claims.

Run from the repository root, using the harness Python environment:

```powershell
.\.venv\Scripts\python.exe -m experiments.replay_live_cases --output experiments/results/live_replay_20260922.json
```

This requires no API key, downloads or third-party packages in the generated
programs. The replay checks normalized source hashes, runs each original entry
point, compares all recorded numeric metrics, and independently recovers the
forecast coverage values and robust-location paired MSE differences. Its exit
code reports reproducibility, not acceptance of scientific claims. It preserves
the original acceptance decisions; additional audit results are not inserted into
the original session checkpoints.

`manifest.json` retains the original dependency declarations, including the
incorrect literal `None` in the robust-location manifest. Do not install that as
a package. This is an unresolved fidelity defect in the generated metadata;
both preserved programs actually import only Python standard-library and local
modules. Raw per-seed results are regenerated by the robust-location program.
