| 会话 | 流程 | 验收 | 独立复跑 |

保形预测的原审稿把覆盖率变化方向说反了。独立复跑得到：提出方法覆盖率 **0.84**、
平均宽度 **2.934**；固定基线为 **0.81**、**2.8824**。入口当时只导出了宽度比较。
全部漂移事件还都发生在最终评测片段之前，这限制了对“漂移时适应能力”的判断。
本轮补充了完整指标输出和负结果分类的提示，但没有改写旧审稿来制造通过。

稳健均值方法的等权平均 MSE 为 **0.06693**，固定截尾基线为 **0.21743**，中位数基线
为 **0.02720**。总体平均值掩盖了场景差异：

| 场景 | 提出方法 − 固定基线的配对 MSE 差 | 配对标准误 |
| --- | ---: | ---: |
| 干净高斯 | 0.001506 | 0.000644 |
| 5% 对称污染 | 0.002882 | 0.000307 |
| 5% 单侧正污染 | 0 | 0 |
| 15% 对称污染 | 0.005323 | 0.001884 |
| 15% 单侧正污染 | -0.762186 | 0.025598 |

每行使用同一场景的 50 对测试结果。MSE 越低越好；正差值表示提出方法较差。
这些配对统计来自独立复跑审计，未插入原会话的执行证据，也不代表新的独立重复实验。
原审稿把部分“假设没有成立”列为 validity 缺陷，并使用了原报告没有提供依据的显著性
表述；这暴露出模型审稿的分类和论证可靠性仍需验证。
